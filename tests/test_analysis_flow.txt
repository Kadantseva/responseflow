uv run pytest -q tests/test_analysis_flow.py
Этот скрипт — интеграционный тест анализа переписки, который проверяет, что система находит сообщение клиента без ответа и сохраняет по нему карточку проблемы (Finding) в SQLite вместе с доказательством — исходным сообщением.

Тест использует реальные компоненты приложения и фикстуры из conftest.py, а не создаёт все зависимости вручную.

Здесь импортируются:
1. Импорты и время анализа
AnalysisService — сервис, который запускает анализ переписок.

UnansweredDetector — детектор, который ищет сообщения без ответа.

datetime, timezone — для задания времени анализа.

2. Подготовка входных сообщений
3. Создание сервиса анализа

message_repository

    Читает сохранённые сообщения

finding_service

    Создаёт или обновляет карточки обнаруженных проблем

window_builder

    Формирует контекст переписки для анализа

UnansweredDetector()

    Ищет сообщения клиентов, оставшиеся без ответа

Сервис анализирует рабочую область north по состоянию на ANALYSIS_TIME.
